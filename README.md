# تطبيق إدارة محلات الموكيت

نسخة Flutter MVP تعمل بالعربية وتحفظ بياناتها محليًا على جهاز Android.

## الوظائف الحالية

- دخول تجريبي حسب الدور: صاحب المؤسسة، المحاسب، البائع، السائق.
- أكثر من محل وربط كل بائع بمحل.
- مخزون الرولات بالطول والعرض واللون والمورد.
- تسعير الجملة: سعر المورد + نصيب مصروفات المؤسسة لكل متر مربع.
- تسجيل البيع والتركيب والغراء والحديد والسائق وطريقة الدفع.
- خصم الطول تلقائيًا من المخزون.
- أنظمة البائع: راتب، عمولة، أو راتب وعمولة.
- مسحوبات ومصروفات البائع والتصفية الشهرية.
- مشاوير السائق حسب المحل والبائع، والسداد كاش أو تحويل بنكي.
- تقرير شهري للمبيعات والربح حسب المحل والبائع.
- حفظ تلقائي للبيانات على الجهاز باستخدام Shared Preferences.

## إخراج APK عبر GitHub Actions

1. أنشئ Repository جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر الـRepository، وليس المجلد الأب.
3. افتح تبويب **Actions** ثم اختر **Build Android APK**.
4. اضغط **Run workflow**. ويبدأ البناء تلقائيًا أيضًا عند أي Push إلى `main` أو `master`.
5. بعد نجاح التشغيل، افتح قسم **Artifacts** ونزّل `carpet-shop-manager-android`.
6. فك الملف المضغوط وثبّت `carpet-shop-manager.apk` على هاتف Android.

قد يطلب الهاتف السماح بالتثبيت من المصدر المستخدم لتنزيل الملف. هذا APK تجريبي وموقّع بمفتاح البناء الافتراضي، وليس مخصصًا للنشر النهائي في Google Play.

## تشغيل محلي

```bash
flutter create --platforms=android --project-name carpet_shop_manager --org com.mashhour.carpet .
flutter pub get
flutter test
flutter run
```

## حدود النسخة الحالية

البيانات محلية على جهاز واحد ولا توجد مزامنة بين هواتف الموظفين حتى الآن. المرحلة التالية للإنتاج هي تسجيل دخول فعلي، صلاحيات حقيقية، قاعدة بيانات سحابية، نسخ احتياطي، وفواتير ضريبية.
